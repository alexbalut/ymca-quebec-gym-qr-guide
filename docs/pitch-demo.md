# Pitch demo (seller walkthrough)

> Lead with: **unofficial mockup for pitching** — not an official YMCA Québec product. No official logos.

Goal: show the **in-club product**, not a marketing site.

Suggested order (~5–8 minutes):

## 1. Member home (`/`)

- “Member walks into YMCA Notre-Dame-de-Grâce.”
- Tabs: **Machines · Workout · Progress · Scan**.
- Toggle EN/FR; mention bilingual tagline.

## 2. Machine guide

- Open **Lat Pulldown** (photos from Unsplash demos — say they’re stock, not club assets).
- Steps / tips / warnings; optional **Add to workout** or **Report an issue**.

## 3. Scan

- Use **Scan** tab or `/scan`. If camera is awkward, Enter code with a token from admin/print.
- “Sticker → phone → guide in the member’s language.”

## 4. Workout + Progress

- Log a few sets; **Save**; show **Progress**.
- “Demo stores history on-device; production could add accounts later.”

## 5. Staff

- `/admin/login` → `admin@ymca-quebec.demo` / `demo1234`.
- Machines dashboard → issues → edit image URLs → print QR sheet → `/admin/insights`.

## 6. Close

- Members: confidence on the floor. Staff: content + maintenance. Owners: usage signal.
- Point to generic sibling if they want non-Écono branding: [gym-machine-qr-guide](https://github.com/alexbalut/gym-machine-qr-guide).

## What not to do

- Don’t imply official partnership or use trademarked logos.
- Don’t add/show a marketing landing — `/` is the product.
